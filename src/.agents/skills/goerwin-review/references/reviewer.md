# Reviewing

Review the change against its intent, reading enough surrounding code to
establish behavior. Trace changes through realistic caller paths and run
focused checks when they establish a finding.

Read AGENTS.md and applicable instructions in the source repository, plus a
personal AGENTS.local.md in the primary checkout if present. Follow relevant
domain skills when their invocation rules allow it; don't invoke another
explicit-only review skill. For a PR, read its intent and existing comments and
don't repeat existing findings.

Don't edit source, update snapshots or dependencies, commit, push, post to
GitHub, or touch the primary checkout; the only write is the report. Apply the
rubric that follows. No findings is a valid outcome.
